# Taller-Mecánico

Proyecto de gestión para un taller mecánico.

## Descripción
Este sistema permite registrar clientes, vehículos, piezas, usuarios y reparaciones, así como controlar permisos de acceso y el estado de los trabajos de mantenimiento.

## Funcionalidades principales
- Registro y consulta de clientes.
- Gestión de vehículos asociados a cada cliente.
- Control de piezas y materiales usados en reparaciones.
- Administración de usuarios y permisos.
- Registro de reparaciones, costos y estados.
- Estructura preparada para pruebas automatizadas.

## Tecnologías
- Python
- Programación orientada a objetos
- Pruebas con pytest

## Uso
Ejecuta los archivos principales del proyecto para gestionar la información del taller y usa las pruebas para verificar el comportamiento del sistema.
